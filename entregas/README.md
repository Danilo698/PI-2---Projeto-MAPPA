# Entregas — Projeto MAPPA

Esta pasta reúne os documentos acadêmicos e os registros das entregas avaliativas do projeto **MAPPA — Modelador Analítico de Painéis para Prevenção de Acidentes**, desenvolvido na disciplina Projeto Integrador II do CEUB.

## 1. Artefatos disponíveis

| Arquivo | Descrição |
|---|---|
| `Artefato_1_MAPPA_PI_II.docx` | Documento de Software — Versão 1, elaborado a partir do projeto desenvolvido no PI I. |
| `Artefato_1_Analise_Usuario_MAPPA.docx` | Artefato 1 — Gestão do Negócio/Domínio, com análise de usuários, personas, mapa de empatia e jornada do usuário. |
| `Artefato_2_MAPPA_PI_II.docx` | Documento referente ao Artefato 2 do Projeto Integrador II. |
| `Artefato_3_Gestao_Produto_MAPPA.docx` | Documento referente ao Artefato 3 — Gestão do Produto. |

**Observação:** existem dois documentos identificados como Artefato 1 porque possuem conteúdos e finalidades diferentes. Ambos foram preservados para conferência com as orientações acadêmicas.

## 2. Organização do projeto

Os documentos desta pasta devem ser utilizados em conjunto com:

- `docs/` — requisitos, backlog, arquitetura e demais documentos técnicos.
- `sprints/` — cronograma e planejamento das Sprints.
- `docs/reunioes/` — registros retrospectivos, pautas e planejamentos de reuniões.
- GitHub Issues — acompanhamento das histórias de usuário e atividades.

## 3. Rastreabilidade das entregas

Cada entrega avaliativa deverá permitir identificar:

- O documento apresentado.
- A Sprint ou etapa correspondente.
- Os requisitos e histórias de usuário relacionados.
- As evidências de implementação e testes, quando disponíveis.
- As revisões realizadas após orientações do professor.

A presença de um documento nesta pasta não significa, por si só, que ele tenha sido submetido, aprovado ou validado.

## 4. Controle de revisões

Este README deverá ser atualizado sempre que ocorrer uma nova submissão, revisão avaliativa, reapresentação ou consolidação relevante para a disciplina.

A situação efetiva de cada entrega deverá ser confirmada pelos registros acadêmicos e pelas evidências disponíveis.
