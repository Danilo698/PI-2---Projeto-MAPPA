# Registro de Decisões — MAPPA

Este diretório guarda decisões relevantes de negócio, produto e arquitetura tomadas ao longo do projeto, no formato de pequenos registros (ADR — Architecture/Decision Record). Cada decisão é um arquivo numerado sequencialmente.

## Modelo

Copie `0000-template.md` para um novo arquivo `NNNN-titulo-curto.md` ao registrar uma decisão.
