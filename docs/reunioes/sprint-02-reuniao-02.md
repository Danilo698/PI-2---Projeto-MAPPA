Para avaliar essas funcionalidades, deverão ser verificados:

- O funcionamento dos filtros.
- A consistência dos indicadores apresentados.
- A correspondência entre os gráficos e os dados tratados.
- A atualização dos resultados após a aplicação de filtros.
- A clareza das informações exibidas no dashboard.

**Situação da implementação:** pendente de verificação no código e nas evidências do projeto.
