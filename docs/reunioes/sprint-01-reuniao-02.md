## Análise técnica

A Sprint 01 tem como objetivo consolidar a base técnica do MAPPA, especialmente o tratamento dos dados utilizados na geração dos indicadores.

Para avaliar a conclusão dessa etapa, é necessário verificar:

- Se o ETL consegue processar os arquivos da PRF.
- Se os dados são padronizados adequadamente.
- Se o tratamento pode ser reproduzido.
- Se os dados tratados estão preparados para utilização no dashboard.
- Se os requisitos e o backlog estão coerentes com as funcionalidades previstas.

**Situação da implementação:** pendente de verificação no código e nas evidências do projeto.
