## Análise técnica

A Sprint 02 prevê o desenvolvimento das funcionalidades de consulta e visualização dos dados de acidentes da Polícia Rodoviária Federal (PRF).

As atividades de planejamento estão relacionadas às seguintes histórias de usuário:

- **US01 — Filtrar acidentes por rodovia e período:** permitir a seleção de dados conforme os filtros definidos pelo usuário.
- **US02 — Visualizar indicadores consolidados:** apresentar informações como quantidade de acidentes, feridos e mortos.
- **US06 — Gráficos por causa e faixa horária:** permitir a análise visual das ocorrências por diferentes categorias.

A proposta é organizar os indicadores na aba *Visão Geral* e apresentar gráficos que facilitem a interpretação dos dados.

A implementação e o funcionamento dessas funcionalidades ainda precisam ser verificados no código e nas evidências do projeto.

## Decisões e definições

**Proposta de organização:**

- Priorizar os indicadores consolidados.
- Relacionar os gráficos aos filtros disponíveis.
- Utilizar os dados tratados pelo ETL como fonte das visualizações.
- Verificar os critérios de aceitação das histórias de usuário antes de considerar as funcionalidades concluídas.

Validação coletiva: pendente.
