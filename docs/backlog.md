## Legenda de prioridade (MoSCoW)
- **Must** — indispensável para o MVP
- **Should** — importante, mas não bloqueia o MVP
- **Could** — desejável, entra se houver tempo
- **Won't** (não há itens nesta rodada) — fora do escopo atual
